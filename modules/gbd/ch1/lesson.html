What is a graph (Qu'est-ce qu'un graphe)

↑ contents
In plain words

A graph is a set of dots joined by lines. The dots are the things you care about (people, routers, cities) and the lines say which pairs are related. Everything else in this chapter is built on this one picture.

  • vertex (sommet)a dot. The set of all dots is V(G).
  • edge (arête)a line between two vertices. Written xy. The set of lines is E(G).
  • order / size (ordre / taille)n = number of vertices, m = number of edges.
  • adjacent, incident, ends (adjacents, incidente, extrémités)if xy is an edge, x and y are adjacent and are the ends of that edge, and the edge is incident to both.
  • simple graph (graphe simple)no loop (boucle) and no two edges between the same pair. All graphs here are simple and finite unless said otherwise.
Worked example
  • V(G0) = {a, b, c, d, e, f, g}, so the order is n = 7.
  • E(G0) = {ab, ac, bc, bd, cd, de, ef, eg}, so the size is m = 8.
  • b and d are adjacent because bd is an edge. a and d are not adjacent because ad is not an edge.
  • Edge bd is incident to b and d; those two are its ends.

Neighbours and degree (Voisinage et degré)

↑ contents
In plain words

The neighbours of a vertex are the vertices it is directly linked to. Its degree counts how many links it has. Twins are two vertices that look identical from the rest of the graph.

  • open neighbourhood (voisinage ouvert)N(u): all neighbours of u, not including u.
  • closed neighbourhood (voisinage fermé)N[u] = N(u) ∪ {u}.
  • degree (degré)d(u) = |N(u)|, the number of edges at u. Max and min degrees are Δ(G) and δ(G).
  • isolated vertex / leaf (sommet isolé / feuille)degree 0 / degree 1 (also called pendant vertex, sommet pendant).
  • false / true twins (faux / vrais jumeaux)non-adjacent vertices with N(u) = N(v) / adjacent vertices with N[u] = N[v].
Worked example
vertex uN(u)d(u)
a{b, c}2
b{a, c, d}3
c{a, b, d}3
d{b, c, e}3
e{d, f, g}3
f{e}1
g{e}1
  • Δ(G0) = 3 (vertices b, c, d, e) and δ(G0) = 1 (leaves f, g). Always 0 ≤ δ ≤ d(u) ≤ Δ ≤ n−1, here 0 ≤ 1 ≤ … ≤ 3 ≤ 6.
  • Check: the degrees add up to 2+3+3+3+3+1+1 = 16 = 2m. Each edge is counted from both ends.
  • N[d] = {b, c, d, e}.
  • Twins: N[b] = {a,b,c,d} = N[c], so b and c are true twins. N(f) = {e} = N(g), so f and g are false twins.
  • For a set S = {a, f}: N(S) = N(a) ∪ N(f) = {b,c} ∪ {e} = {b,c,e} and N[S] = N(S) ∪ S = {a,b,c,e,f}.

Subgraphs (Sous-graphes)

↑ contents
In plain words

A subgraph is what is left when you keep only part of a graph. Two common ways: keep some vertices and every line between them (induced), or keep every vertex but only some of the lines (partial).

  • induced subgraph (sous-graphe induit)G[A] for A ⊆ V: vertex set A and every edge of G with both ends in A.
  • vertex deletion (suppression de sommet)G − u = G[V ∖ {u}]: remove u and all its edges.
  • partial graph (graphe partiel)G_U for U ⊆ E: all the vertices, but only the edges in U.
Worked example
  • G0[{b,c,d,e}]: keep edges with both ends in the set: bc, bd, cd, de. So 4 vertices and 4 edges (ab, ac, ef, eg each have an end outside).
  • G0 − d: 6 vertices left. Edges lost = d(d) = 3 (bd, cd, de), so 8 − 3 = 5 edges remain: ab, ac, bc, ef, eg.
  • G_U: still all 7 vertices, but only the 4 chosen edges. The vertices c and g end up isolated.

Chains and chords (Chaînes et cordes)

↑ contents
In plain words

A chain is a trip along edges: vertex, edge, vertex, and so on. In this course "chaîne" is what many textbooks call a walk. Add restrictions (no repeated vertex, no repeated edge) and you get the more familiar names.

  • chain (chaîne)P(u,v) = (u0, u1, …, un) with u0 = u, un = v and each u_i u_(i+1) an edge. Its length is n, the number of steps.
  • initial / final / interior vertices (extrémités initiale / finale, intérieurs)the first, the last, and everything in between.
  • elementary chain (chaîne élémentaire)no repeated vertex (a path in most books).
  • simple chain (chaîne simple)no repeated edge (a trail in most books). Elementary implies simple.
  • chord (corde)an edge between two vertices that are not consecutive on the chain.
  • induced chain (chaîne minimale induite)an elementary chain with no chord.
Worked example
  • (a,b,d,e,f): 5 distinct vertices, so elementary, length 4. Non-consecutive pairs ad, ae, af, be, bf, df are all non-edges, so no chord: it is induced.
  • (b,c,a,b,d): edges bc, ca, ab, bd are all different, so simple. But b appears twice, so it is not elementary. Length 4.
  • (a,b,c,d): elementary, length 3. Non-consecutive pairs: ac is an edge (chord), bd is an edge (chord), ad is not. Two chords, so it is not induced.

Cycles (Cycles)

↑ contents
In plain words

A cycle is a closed trip: you leave a vertex and come back to it without using any edge twice. Two famous special cases ask a different question. Hamiltonian: can you visit every vertex once? Eulerian: can you use every edge once?

  • cycle (cycle)a simple chain with n ≥ 3 whose two ends coincide. Its length is its number of edges.
  • elementary cycle (cycle élémentaire)no repeated vertex. C_n denotes a cycle on n vertices.
  • Hamiltonian cycle (cycle hamiltonien)passes through every vertex exactly once.
  • Eulerian cycle (cycle eulérien)uses every edge exactly once.
  • even / odd cycle (cycle pair / impair)by the parity of its length.
Worked example
  • In G0: (b,c,d,b) is a triangle, length 3, odd. (a,b,d,c,a) is length 4, even (and bc is a chord inside it).
  • G0 has no Hamiltonian cycle: leaves f and g have only one edge, but a cycle needs two edges at every vertex it visits. G0 has no Eulerian cycle either, since some degrees are odd.
  • Bowtie: degrees are 2, 2, 4, 2, 2, all even, so an Eulerian cycle exists: c→a→b→c→d→e→c uses all 6 edges once. No Hamiltonian cycle, since c would be visited twice.
  • K4: Hamiltonian cycle 1-2-3-4-1 visits 4 vertices once each. Every degree is 3 (odd), so no Eulerian cycle.
  • Rule of thumb (Euler): a connected graph has an Eulerian cycle exactly when every degree is even.

Distance and balls (Distance et boules)

↑ contents
In plain words

The distance between two vertices is the fewest steps needed to get from one to the other. Eccentricity asks how far a vertex is from the vertex that is farthest away. The diameter is the biggest eccentricity, the longest of all shortest trips.

  • distance (distance)d(u,v) = length of a shortest chain from u to v.
  • eccentricity (excentricité)exc(v) = max over w of d(v,w).
  • diameter (diamètre)diam(G) = max over v of exc(v).
  • ball (boule)B_r(v): all vertices at distance at most r from v. For r = 1 it is exactly N[v].
Worked example

  • B_2(b): distance 1 gives a, c, d; distance 2 adds e (via d). f and g are at distance 3, so they are out.
  • Careful: the course writes B_r(v) = N[v]. That is true only for r = 1; for bigger r the ball is larger.

Connectivity (Connexité)

↑ contents
In plain words

A graph is connected if you can travel from any vertex to any other along edges. If not, it breaks into separate pieces that cannot reach each other. Those pieces are the components.

  • connected graph (graphe connexe)every pair of vertices is joined by a chain.
  • connected component (composante connexe)a connected subgraph that cannot be enlarged (maximal for inclusion).
Worked example
  • F from x1: distance 1 gives x2; distance 2 gives x3, x4; distance 3 gives x5, x6. All 6 vertices are reached, so F is connected.
  • H from y1: distance 1 gives y2, y3; distance 2 gives y4. Nothing else is reachable.
  • So y5, y6, y7 form a second piece: the components are {y1,y2,y3,y4} and {y5,y6,y7}. Sizes 4 + 3 = 7 vertices, 2 components.

Complement, cliques and stable sets (Complémentaire, cliques et stables)

↑ contents
In plain words

The complement flips a graph: it joins exactly the pairs that were not joined. A clique is a group where everyone is linked to everyone. A stable set is the opposite: nobody is linked to anybody. A clique in G is a stable set in its complement.

  • complement (complémentaire)Ḡ: same vertices, xy ∈ E(Ḡ) iff xy ∉ E(G). If G has order n and size m, then Ḡ has size C(n,2) − m.
  • complete graph (graphe complet)K_n: all n vertices pairwise adjacent. Its complement S_n has no edge.
  • clique, clique number (clique, nombre de clique)vertices inducing a complete graph. ω(G) = size of the largest one.
  • stable set, stability number (stable (ensemble indépendant), nombre de stabilité)α(G) = size of the largest stable set.
  • domination-stable number (nombre de domination stable)i(G) = size of the smallest maximal stable set (see section 12).
Worked example
  • Complement of P4: n = 4, m = 3, so C(4,2) − 3 = 6 − 3 = 3 edges. They are ac, ad, bd, which form the path c-a-d-b: P4 is its own complement.
  • Clique in G0: ab, ac, bc are edges, so {a,b,c} is a clique. No 4-clique exists: only b,c,d,e have degree 3, and be, ce are missing. Hence ω(G0) = 3.
  • Stable set in G0: none of ad, af, ag, df, dg, fg is an edge, so {a,d,f,g} is stable (size 4).
  • Why not 5? Cover the vertices with 4 cliques {a,b,c}, {d,e}, {f}, {g}. A stable set takes at most one vertex per clique, so α(G0) = 4.

Worked story: the dinner party (Exemple 1 : le dîner)

↑ contents
In plain words

You host 7 guests: Ahmed (A), Chahinez (C), Imane (I), Karine (K), Lina (L), Narimene (N) and Yamina (Y). Some pairs dislike each other. Who can you invite so that everybody gets along, and how many at most? Turn guests into vertices and "dislikes" into edges.

  • model (modélisation)vertex = guest, edge = two guests who dislike each other (this is the "tableau d'adjacence" below).
  • goal (objectif)a group where nobody dislikes anybody is a stable set. We want the largest one: α(G).

Matchings (Couplages)

↑ contents
In plain words

A matching is a set of edges that do not touch each other: think of pairing people up for a dance, each person in at most one pair. The more edges you can pair up, the better.

  • matching (couplage)a set M ⊆ E of pairwise non-adjacent edges.
  • saturated / unsaturated (saturé / insaturé)a vertex is saturated if some edge of M ends there.
  • perfect matching (couplage parfait)saturates every vertex. Needs n even. It is automatically maximum.
  • maximum matching (couplage maximum)no matching has more edges.
  • maximal matching (couplage maximal)no edge can be added. Might still be smaller than the maximum.
Worked example
  • Example 2 on the dinner graph (n = 7, m = 9).
  • Perfect matching: impossible. Each edge saturates 2 vertices, so 7 vertices would need 3.5 edges.
  • Maximum matching: at most ⌊7/2⌋ = 3 edges, and {CL, AK, IY} reaches 3, so the maximum size is 3.
  • Maximal matching: take {AC, IN}. The unsaturated vertices are K, L, Y. K only knows A, I; L only knows C, N; Y only knows I, N. All are taken, so nothing can be added. Size 2 is less than 3, so maximal does not mean maximum.

Covers and four key identities (Transversaux, recouvrements et propriétés)

↑ contents
In plain words

A cover is a set that "touches everything". Vertices can cover edges (transversal); edges can cover vertices (recouvrement). Covers are the flip side of stable sets and matchings, which gives four neat identities.

  • transversal / vertex cover (transversal)a vertex set T such that every edge has an end in T.
  • edge cover (recouvrement)an edge set R such that every vertex is an end of some edge of R.
  • Property 1 (Propriété 1)S is stable iff V ∖ S is a transversal. So max|S| + min|T| = n.
  • Property 3 (Gallai) (Propriété 3)max|M| + min|R| = n (for graphs without isolated vertices).
  • Property 4 (bipartite only) (Propriété 4)if G is bipartite: max|M| = min|T| and max|S| = min|R|.
Worked example
  • Dinner graph, n = 7. Max stable set has size 3, so by Property 1 the minimum transversal has size 7 − 3 = 4: V ∖ {C,K,Y} = {A,I,L,N}. Check: AC, AK, AN (A), CL, LN (L), IK, IN, IY (I), NY (N). All 9 edges hit.
  • Max matching is 3, so by Property 3 the minimum edge cover has size 7 − 3 = 4: {CL, AK, IY, NA} touches C,L,A,K,I,Y,N. All 7 vertices covered.
  • Property 4 fails here: max|M| = 3 but min|T| = 4. The graph is not bipartite (the triangle I-N-Y is an odd cycle).
  • K_{2,3} is bipartite, n = 5: max|M| = 2 = min|T| (the two vertices u1, u2), and max|S| = 3 = min|R|. Also 3 + 2 = 5 = n for Properties 1 and 3.

Minimal vs minimum (Minimal vs minimum)

↑ contents
In plain words

Minimal means "you cannot remove anything and keep the property". Minimum means "nothing smaller exists at all". Same idea for maximal (cannot add anything) and maximum (nothing bigger exists). Minimum always implies minimal, but not the other way round.

  • minimal / minimum (minimal / minimum)no proper subset has the property / no smaller set has it.
  • maximal / maximum (maximal / maximum)no larger set contains it / no larger set exists.
Worked example
  • {b,e} is stable. Try adding: a, c, d touch b; f, g touch e. Nothing fits, so it is maximal. Its size 2 equals i(G0), the smallest a maximal stable set can be.
  • {a,d,f,g} has size 4 = α(G0), so it is maximum. Maximal stable sets of size 2 and size 4 both exist in the same graph.
  • {a,c,d,f,g} is a transversal. Remove a and ab is uncovered; remove c: bc; remove d: bd; remove f: ef; remove g: eg. So it is minimal.
  • {b,c,e} has size 7 − 4 = 3 = n − α, so it is the minimum transversal (it is the complement of the maximum stable set).

Regular and complete graphs (Graphes réguliers et complets)

↑ contents
In plain words

In a regular graph every vertex has exactly the same degree. In a complete graph everybody is linked to everybody, which is the most regular a graph can be.

  • k-regular graph (graphe k-régulier)every vertex has degree k. Cycles C_n are 2-regular.
  • complete graph (graphe complet)K_n is (n−1)-regular, with order n and size n(n−1)/2.
  • Petersen graph (graphe de Petersen)a famous 3-regular graph on 10 vertices.
Worked example
  • Counting edges of a k-regular graph: the degrees add up to n·k, and each edge is counted twice, so m = n·k / 2.
  • C5: 5·2/2 = 5 edges.
  • K5: 5·4/2 = 10 edges, which matches n(n−1)/2 = 5·4/2 = 10.
  • Petersen: 10·3/2 = 15 edges (5 outer, 5 spokes, 5 inner).

Bipartite graphs (Graphes bipartis)

↑ contents
In plain words

A graph is bipartite if you can split its vertices into two teams so that every edge goes between the teams and none stays inside a team. The quick test: look for an odd cycle. No odd cycle means bipartite.

  • bipartite graph (graphe biparti)vertices split into two stable sets V1, V2, every edge has one end in each.
  • odd-cycle test (cycle impair)G is bipartite if and only if it has no cycle of odd length.
  • complete bipartite graph (graphe biparti complet)K_{n,m}: all n·m edges between the two sides. Order n+m, size n·m.
  • r-regular complete bipartite (biparti complet r-régulier)it is K_{r,r}: order 2r, size r².
Worked example
  • C6: teams {1,3,5} and {2,4,6}. Each of the 6 edges joins a blue vertex to an orange one. Even cycle, so bipartite.
  • C5: put 1 in A, then 2 in B, 3 in A, 4 in B. Vertex 5 touches 4 (B) and 1 (A), so it fits in neither team. The cycle has odd length 5, so C5 is not bipartite.
  • K_{3,2}: order 3 + 2 = 5, size 3·2 = 6.
  • K_{3,3} is 3-regular: order 2·3 = 6, size 3² = 9.

Multipartite graphs, stars, trees and forests (Multipartis, étoiles, arbres et forêts)

↑ contents
In plain words

Stretch bipartite to any number of teams and you get multipartite graphs. A star is the simplest complete bipartite graph. A tree is a connected graph with no cycle, and a forest is a bunch of trees side by side.

  • complete multipartite graph (multiparti complet)K_{n1,…,nk}: k stable groups, two vertices adjacent iff they are in different groups.
  • star (étoile)K_{1,n}: one centre joined to n leaves.
  • tree (arbre)connected, no cycle. A tree on n vertices has exactly n−1 edges.
  • forest (forêt)every connected component is a tree. With c components it has n−c edges.
Worked example
  • K_{3,2,2}: 7 vertices. Between groups: 3·2 + 3·2 + 2·2 = 6 + 6 + 4 = 16 edges.
  • Second way: all pairs C(7,2) = 21, minus the pairs inside groups 3 + 1 + 1 = 5, gives 21 − 5 = 16.
  • K_{1,5}: 6 vertices, 5 edges.
  • Tree above: n = 7, m = 6 = n − 1. Forest above: n = 8 vertices in c = 3 components (4 + 3 + 1), so m = 8 − 3 = 5 edges: 3 in the blue tree, 2 in the orange one, 0 in the single vertex.

t-transitive closure (Fermeture t-transitive)

↑ contents
In plain words

The closure G^t keeps every vertex of G and adds a direct edge between any two vertices that were at most t steps apart. It turns "friends of friends" into direct links.

  • t-transitive closure (fermeture t-transitive)G^t: u and v are adjacent iff d_G(u,v) ≤ t. So G^1 = G.
  • contact graph (graphe de contacts)direct contacts plus contacts of contacts is exactly G².
Worked example
  • Path 1-2-3-4-5. Pairs at distance 1: 4. Distance 2 (13, 24, 35): 3 more, total G² has 7 edges. Distance 3 (14, 25): total 9. Distance 4 (15): total 10.
  • 10 = C(5,2), so G⁴ is the complete graph K5. In general, G^t is complete once t ≥ diam(G).
  • Contacts: Sara–Tom, Tom–Uma, Uma–Vic, Tom–Wen. In G² the new edges are Sara–Uma, Sara–Wen, Uma–Wen (all via Tom) and Tom–Vic (via Uma): 4 new, 4 + 4 = 8 edges.
  • Sara's direct and indirect contacts: N_(G²)(Sara) = {Tom, Uma, Wen}. Vic is at distance 3, so not included.

Hypergraphs (Hypergraphes)

↑ contents
In plain words

In a graph an edge links exactly two vertices. A hypergraph lets one "edge" link any number of vertices at once. It is the natural tool when a relation involves a whole group, like a team or a meeting.

  • hypergraph (hypergraphe)H = (V, E): V is a set of vertices, E a family of hyperedges, each a subset of V.
  • hyperedge (hyperarête)a subset of vertices of any size (1, 2, 3, …).
  • graph as hypergraph (graphe vu comme hypergraphe)an ordinary graph is a hypergraph whose hyperedges all have size 2.
Worked example
  • First figure: V = {v1, …, v7} and E = {e1, e2, e3, e4} with e1 = {v1,v2,v3}, e2 = {v2,v3}, e3 = {v3,v5,v6}, e4 = {v4}. Sizes 3, 2, 3, 1.
  • How many hyperedges contain each vertex: v1:1, v2:2, v3:3, v4:1, v5:1, v6:1, v7:0. Total 9 = 3+2+3+1. Vertex v7 belongs to none.
  • Teams: team 1 = {Ada, Bo, Cy} (3 people), team 2 = {Cy, Di, Ed, Flo, Gus} (5 people), team 3 = {Hal} (1 person). Cy sits in two teams.
  • With an ordinary graph, team 2 would need C(5,2) = 10 edges, and you could not tell it apart from 10 unrelated pairs. A hyperedge records "these five form one team" in one object.

Graph products (Produits de graphes)

↑ contents
In plain words

A product builds a bigger graph from two smaller ones. Its vertices are pairs (x,y) with x from G and y from H. The four products differ only in the rule that decides when two pairs are joined. We use G = P2 (a single edge a-b) and H = P3 (a path 1-2-3).

  • direct product (produit direct)G × H: (x1,y1) ~ (x2,y2) iff x1x2 ∈ E(G) and y1y2 ∈ E(H). Both coordinates must move.
  • Cartesian product (produit cartésien)G □ H: one coordinate moves along an edge, the other stays put.
  • lexicographic product (produit lexicographique)G ⊗ H: x1x2 ∈ E(G) (any y), or x1 = x2 and y1y2 ∈ E(H).
  • total (strong) product (produit total)G ⊠ H: Cartesian moves plus direct moves.
Worked example
  • Direct: a is adjacent to b in P2, and 1~2, 2~3 in P3. Edges: a1-b2, a2-b1, a2-b3, a3-b2. Count: 4.
  • Cartesian: 2 copies of P3 (2 edges each = 4) plus 3 vertical edges a_i-b_i. Count: 4 + 3 = 7.
  • Lexicographic: since ab ∈ E(P2), every a_i joins every b_j: 3·3 = 9. Add the P3 edges inside each copy: 2 + 2 = 4. Count: 13.
  • Total: Cartesian 7 + direct 4 = 11. So G×H and G□H are subgraphs of G⊠H, which is a subgraph of G⊗H (4, 7 ≤ 11 ≤ 13).
  • Colouring check: χ(P2×P3) = 2 = min(2,2) and χ(P2□P3) = 2 = max(2,2). Both products are bipartite.

Hypercubes and Hamming graphs (Hypercube et graphes de Hamming)

↑ contents
In plain words

The hypercube is the graph of all binary words of length n, where two words are neighbours when they differ in exactly one bit. Hamming graphs do the same with an alphabet of any size.

  • hypercube (hypercube)Q_n: vertices {0,1}^n, adjacent iff they differ in one coordinate. Q_n = K2 □ … □ K2.
  • distance in Q_n (distance)the number of coordinates where the two words differ.
  • Hamming graph (graphe de Hamming)H(d,q): Cartesian product of d copies of K_q. H(d,2) = Q_d.
Worked example

Grids and tori (Grilles et tores)

↑ contents
In plain words

A grid is a chessboard of vertices where each one links to its neighbours up, down, left and right. A torus is the same board with the edges glued around, like a donut or the screen of the game Snake.

  • grid (grille)Cartesian product of paths. The k × n grid has vertex set {1..k} × {1..n}.
  • torus (tore)Cartesian product of cycles.
  • Manhattan distance (distance de Manhattan)d1(u,v) = Σ |v_i − u_i|, the number of steps on the grid. Also called Lee distance on the torus.
  • strip / half-strip (bande / demi-bande)S_k: k rows, infinite in both directions. S_k^+: infinite in one direction only.
Worked example
  • Grid 3 × 4: 12 vertices. Horizontal edges: 3 rows × 3 = 9. Vertical edges: 4 columns × 2 = 8. Total 9 + 8 = 17, which is k(n−1) + n(k−1).
  • Manhattan distance from A = (1,1) to B = (3,4): |3−1| + |4−1| = 2 + 3 = 5.
  • Torus C3 □ C4: 12 vertices, each of degree 2 + 2 = 4, so 12·4/2 = 24 edges. Rows are 4-cycles (3 × 4 = 12 edges), columns are triangles (4 × 3 = 12 edges).
  • On the torus the same trip is shorter, using the wrap-around: row gap min(2, 3−2) = 1, column gap min(3, 4−3) = 1, so the distance is 1 + 1 = 2 (orange stubs).

Homomorphisms (Homomorphismes de graphes)

↑ contents
In plain words

A homomorphism is a way of mapping one graph onto another so that edges stay edges: if two vertices are adjacent, their images must be adjacent too. It squeezes a graph into another without breaking any link.

  • homomorphism (homomorphisme)a map f: V1 → V2 such that uv ∈ E1 implies f(u)f(v) ∈ E2.
  • colouring as homomorphism (coloration)a proper k-colouring of G is exactly a homomorphism G → K_k: colours are the vertices of K_k.
Worked example
  • Take f(a)=1, f(b)=2, f(c)=1, f(d)=2.
  • Edge ab goes to 12, bc to 21, cd to 12. Each is an edge of K2, so f is a homomorphism.
  • This f is also a proper 2-colouring of P4 (colour 1 and colour 2 alternate).
  • No homomorphism K3 → K2 exists: the 3 mutually adjacent vertices would need 3 different images, but K2 has only 2 vertices.

Colouring and Brooks' theorem (Coloration et théorème de Brooks)

↑ contents
In plain words

Colouring a graph means giving each vertex a colour so that adjacent vertices never share one. The chromatic number is the fewest colours you can get away with. Brooks' theorem says you almost never need more than the maximum degree.

  • proper colouring, k-colourable (coloration propre, k-colorable)adjacent vertices get different colours from {1..k}.
  • chromatic number (nombre chromatique)χ(G): the smallest k for which G is k-colourable. G is k-chromatic if χ(G) = k.
  • Brooks' theorem (théorème de Brooks)for a connected graph with max degree Δ: χ(G) ≤ Δ, except for complete graphs and odd cycles, where χ(G) = Δ + 1.

  • K4 needs 4: its 4 vertices are pairwise adjacent, so all colours differ.
  • Note: the course states the exception case as χ ≤ Δ + 1. For cliques and odd cycles it is exactly Δ + 1.

Isomorphism (Isomorphisme)

↑ contents
In plain words

Two graphs are isomorphic when they are the same graph drawn differently: you can rename the vertices of one to get the other, with every edge matching an edge and every non-edge matching a non-edge.

  • isomorphic graphs (graphes isomorphes)there is a bijection f: V1 → V2 with uv ∈ E1 iff f(u)f(v) ∈ E2.
  • quick test (test rapide)isomorphic graphs have the same order, size and sorted list of degrees. If any differs, they are not isomorphic.
Worked example
  • Rename with f(u1)=v3, f(u2)=v5, f(u3)=v1, f(u4)=v2, f(u5)=v4. Each of the 6 edges of G goes to an edge of H:

u4u1v2v3✓ v2v3 ∈ E(H)

  • Bowtie: 5 vertices, 6 edges too, but degrees 4,2,2,2,2 versus the house 3,3,2,2,2. The degree lists differ, so the bowtie is not isomorphic to G.

Words and metrics (Alphabet, mot, métrique)

↑ contents
In plain words

A word is a list of letters from an alphabet. A metric is a rule for measuring how far apart two words are. Turn words into vertices, join those at distance 1, and each metric gives a familiar graph.

  • alphabet, word (alphabet, mot)an alphabet Σ is a set of letters; a word of length k is an element of Σ^k. The usual one is binary, {0,1}.
  • Hamming metric (métrique de Hamming)number of positions where the words differ.
  • Manhattan metric (métrique de Manhattan)Σ |u_i − v_i|, treating letters as numbers on a line.
  • Lee metric (métrique de Lee)Σ min(|u_i − v_i|, l − |u_i − v_i|): letters sit on a circle, so 0 and l−1 are neighbours.

  • Binary words add with 0+0=0, 0+1=1, 1+1=0. For u = (1,0,1,1) and v = (0,1,1,0): u + v = (1,1,0,1), and the Hamming distance is the number of 1s in u+v, which is 3.
  • Words of length k over l letters give graphs: Hamming gives the Hamming graph, Manhattan gives the grid, Lee gives the torus. For l = 4, k = 2 (16 vertices): Hamming graph K4 □ K4 has 16·6/2 = 48 edges, the grid P4 □ P4 has 2·4·3 = 24, the torus C4 □ C4 has 16·4/2 = 32.
  • With a binary alphabet all three metrics agree and every graph is the hypercube Q_k.

Notes on the original text (Remarques sur le cours)

↑ contents
Worth double-checking with your instructor
  • The ball formula Br(v) = N[v] holds for r = 1 only (section 6).
  • Brooks' theorem: for complete graphs and odd cycles the chromatic number is exactly Δ + 1, not just at most Δ + 1 (section 22).
  • Section 18 calls two statements "conjectures". As far as I know, Hedetniemi's conjecture (1966) about χ(G × H) was disproved by Shitov in 2019, and χ(G □ H) = max{χ(G), χ(H)} is a proven theorem (Sabidussi, 1957). Vizing's name is attached to a different conjecture, about domination number.
  • H(2,3) is K3 □ K3: its rows and columns are triangles, so it has 18 edges, not the 12 of a plain 3×3 grid (section 19).
  • Property 3 (max|M| + min|R| = n) needs a graph with no isolated vertex, since an isolated vertex can never be covered by an edge (section 11).
