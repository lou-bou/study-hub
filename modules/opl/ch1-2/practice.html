A

Word problem to LP (modélisation)

↑ contents
In plain words

You are not asked to solve anything here. Only write the model. Solutions give the optimum so you can see what the model should produce.

Template to fill in. Variables: what quantities do I choose? · Objective: max or min of what? · One constraint per limited resource (or per requirement) · Sign: x ≥ 0.
A1

A carpenter makes tables (profit 30) and chairs (profit 25). A table needs 3 h of carpentry and 1 h of painting; a chair needs 2 h of carpentry and 1 h of painting. He has 18 h of carpentry and 7 h of painting. Maximise the profit.

Show answer
max z = 30t + 25c 3t + 2c ≤ 18 (carpentry) t + c ≤ 7 (painting) t, c ≥ 0

Corners: (0,0) → 0, (6,0) → 180, (4,3) → 195, (0,7) → 175. Optimum: t = 4, c = 3, z = 195.

A2

A diet uses two foods. Food F1 costs 2 per unit and gives 3 protein and 1 iron. Food F2 costs 3 per unit and gives 1 protein and 2 iron. The diet needs at least 9 protein and at least 8 iron. Minimise the cost.

Show answer
min z = 2a + 3b 3a + b ≥ 9 (protein) a + 2b ≥ 8 (iron) a, b ≥ 0

Requirements give "≥" constraints, so this is a min problem with "≥". Optimum: a = 2, b = 3, cost = 13.

A3

A factory makes exactly 10 units in total of products X and Y (profits 4 and 5). It must make at least 2 units of X and at most 6 units of Y. Maximise the profit.

Show answer
max z = 4x + 5y x + y = 10 (equality) x ≥ 2 (proper constraint, not just a sign condition) y ≤ 6 x, y ≥ 0

Optimum: x = 4, y = 6, z = 46. Note that "at least 2" is stronger than x ≥ 0, so it counts as a proper constraint.

A4

Transport: depot D1 has stock 40 and D2 has stock 30. Shop S1 needs 30 and S2 needs 40. Unit costs: D1→S1 = 2, D1→S2 = 5, D2→S1 = 4, D2→S2 = 3. Minimise the total cost.

Show answer
min Z = 2x₁₁ + 5x₁₂ + 4x₂₁ + 3x₂₂ x₁₁ + x₁₂ = 40 (stock D1) x₂₁ + x₂₂ = 30 (stock D2) x₁₁ + x₂₁ = 30 (demand S1) x₁₂ + x₂₂ = 40 (demand S2) x_ij ≥ 0

Total stock 70 = total demand 70, so the problem is balanced. Optimum: x₁₁ = 30, x₁₂ = 10, x₂₁ = 0, x₂₂ = 30, cost = 200 (60 + 50 + 0 + 90).

B

Conversion drills (forme canonique et standard)

↑ contents
In plain words

For each problem, (a) write the canonical form (max, all "≤", all variables ≥ 0), then (b) add one slack variable per inequality to get the standard form. Apply the rules in order.

Rules to keep in view.
You haveDo
min zmaximise −z
≥multiply both sides by −1 to get ≤
=write both ≤ and ≥
x ≤ 0x = −y, y ≥ 0
free xx = u − v, u, v ≥ 0
standard formadd a slack s ≥ 0 to each "≤" (objective coefficient 0)
B1

min z = 4x₁ + 3x₂ subject to x₁ + x₂ ≥ 3, 2x₁ + x₂ ≥ 4, x₁, x₂ ≥ 0.

Show answer
(a) max (−z) = −4x₁ − 3x₂ −x₁ − x₂ ≤ −3 −2x₁ − x₂ ≤ −4 x₁, x₂ ≥ 0 (b) max −4x₁ − 3x₂ + 0s₁ + 0s₂ −x₁ − x₂ + s₁ = −3 −2x₁ − x₂ + s₂ = −4 x₁, x₂, s₁, s₂ ≥ 0

All three forms agree: x = (1, 2), original min z = 10, canonical max(−z) = −10, slacks both 0.

B2

max z = 3x₁ + 2x₂ subject to x₁ + x₂ = 5, x₁ − x₂ ≥ −1, x₁, x₂ ≥ 0.

Show answer
(a) max 3x₁ + 2x₂ x₁ + x₂ ≤ 5 −x₁ − x₂ ≤ −5 (the "≥ 5" half of the equality) −x₁ + x₂ ≤ 1 (from x₁ − x₂ ≥ −1) x₁, x₂ ≥ 0 (b) max 3x₁ + 2x₂ + 0s₁ + 0s₂ + 0s₃ x₁ + x₂ + s₁ = 5 −x₁ − x₂ + s₂ = −5 −x₁ + x₂ + s₃ = 1 all variables ≥ 0

Optimum: x = (5, 0), z = 15, slacks (0, 0, 6).

B3

max z = 3x₁ − x₂ subject to x₁ + x₂ ≤ 4, x₂ ≥ −2, x₁ ≥ 0, x₂ ≤ 0.

Show answer

Since x₂ ≤ 0, set x₂ = −y with y ≥ 0. Then x₂ ≥ −2 becomes y ≤ 2.

(a) max 3x₁ + y x₁ − y ≤ 4 y ≤ 2 x₁, y ≥ 0 (b) max 3x₁ + y + 0s₁ + 0s₂ x₁ − y + s₁ = 4 y + s₂ = 2 all variables ≥ 0

Optimum: x₁ = 6, y = 2 (so x₂ = −2), z = 20, slacks (0, 0).

B4

max z = x₁ + 2x₂ subject to x₁ + x₂ ≤ 5, x₁ ≤ 4, x₂ ≥ −1, x₁ ≥ 0, with x₂ free.

Show answer

Set x₂ = u − v with u, v ≥ 0. Then x₂ ≥ −1 becomes −u + v ≤ 1.

(a) max x₁ + 2u − 2v x₁ + u − v ≤ 5 x₁ ≤ 4 −u + v ≤ 1 x₁, u, v ≥ 0 (b) max x₁ + 2u − 2v + 0s₁ + 0s₂ + 0s₃ x₁ + u − v + s₁ = 5 x₁ + s₂ = 4 −u + v + s₃ = 1 all variables ≥ 0

Optimal value: z = 10, for example x₁ = 0, u = 5, v = 0 (so x₂ = 5), slacks (0, 4, 6).

C4

max z = 2x₁ + 2x₂ subject to x₁ + x₂ ≤ 3, x₁ ≤ 2, x₂ ≤ 2, x ≥ 0. What is special about the optimum?

Aid. Corners: (0,0), (2,0), (2,1), (1,2), (0,2). Compare the slope of the objective lines with the edge x₁ + x₂ = 3.
Show answer
Corner(0,0)(2,0)(2,1)(1,2)(0,2)
z04664

Two corners tie. The objective lines (x₁ + x₂ = constant) are parallel to the edge x₁ + x₂ = 3, so every point on the edge from (2,1) to (1,2) is optimal, z = 6. The optimum is not unique.
