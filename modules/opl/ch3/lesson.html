The simplex method

You must choose how much to make of each product, resources are limited, and you want the most profit. The simplex method finds the best plan by hopping from corner to corner of the possible plans, always to a better one. (La méthode du simplexe)

1

Turning a story into equations (mise en équation)

↑ contents
In plain words

A linear program is a “best plan” question. You choose some quantities (how many desks of each kind). Each unit earns a fixed amount, so the total profit is a simple sum. And you have limits: you can't sell more than the market wants, and wood and time run out.

Writing the model means writing three things: the unknowns, the profit formula, and one inequality (≤) for each limit.

  • decision variable (variable de décision)a quantity you choose.x₁ = number of luxury desks
  • objective function (fonction économique)the formula to make as big as possible (here the profit Z).Z = 7x₁ + 5x₂
  • constraint (contrainte)one limit, written as an inequality.wood: x₁ + x₂ ≤ 500
  • feasible region (domaine des solutions réalisables)all plans that respect every limit. With two unknowns you can draw it: a shape with straight sides.
Worked example · the desk maker (Example 8.4.3, l'ébéniste)

A cabinet-maker makes luxury and standard desks. The market can take at most 300 luxury and 400 standard desks. There is wood for 500 desks of any kind. A luxury desk takes twice as long to make as a standard one, and there is time for 700 standard desks. Each luxury desk earns 7, each standard desk 5. How many of each should be made?

SentenceBecomes
How many luxury / standard desks?x1 = luxury, x2 = standard, both ≥ 0
Each luxury desk earns 7, each standard 5Z = 7x1 + 5x2, to maximise
At most 300 luxury desks soldx1 ≤ 300
At most 400 standard desks soldx2 ≤ 400
Wood for 500 desks of any kindx1 + x2 ≤ 500
Time for 700 standard desks; a luxury desk takes 2 units of time2x1 + x2 ≤ 700
  • Check a plan, P = 100 luxury and 200 standard: 100 ≤ 300 ✓, 200 ≤ 400 ✓, 100 + 200 = 300 ≤ 500 ✓, 2·100 + 200 = 400 ≤ 700 ✓. Allowed, and the profit is 7·100 + 5·200 = 1700.

Leftover variables (variables d'écart)

↑ contents
In plain words

The simplex method only works with equalities (=), not with ≤. The trick: for each limit, add one new variable that holds what is left over.

Wood: “x1 + x2 ≤ 500” becomes “x1 + x2 + x5 = 500”, where x5 is the wood not used. A leftover is never negative. It is 0 exactly when that resource is completely used up.

  • slack variable (variable d'écart)the leftover of one limit: capacity minus what the plan uses.x₅ = 500 − x₁ − x₂
  • standard form (forme standard)the model with every limit written as an equality, all variables ≥ 0.
  • for a ≥ limit (contrainte ≥)subtract instead: a₁x₁ + … − e₁ = b₁, e₁ ≥ 0 (the amount above the minimum).
Worked example · leftovers of the desk maker
The desk example so far
  • x1 = number of luxury desks, x2 = number of standard desks.
  • Profit to make as big as possible: Z = 7x1 + 5x2 (7 per luxury desk, 5 per standard desk).
  • Luxury sales: x1 ≤ 300 · standard sales: x2 ≤ 400 · wood: x1 + x2 ≤ 500 · time: 2x1 + x2 ≤ 700.
  • One leftover per limit: x3 for luxury sales, x4 for standard sales, x5 for wood, x6 for time.
  • The four equations: x1 + x3 = 300, x2 + x4 = 400, x1 + x2 + x5 = 500, 2x1 + x2 + x6 = 700. All six variables ≥ 0.
  • At P = (100, 200): x3 = 300 − 100 = 200, x4 = 400 − 200 = 200, x5 = 500 − 300 = 200, x6 = 700 − 400 = 300. All positive: no resource is used up at P.

Corners and the starting table (solutions de base, tableau initial)

↑ contents
In plain words

The best plan is always at a corner of the shape: if you slide a “same profit” line outward, the last point it touches is a corner. So the simplex only visits corners.

At a corner, some variables are exactly 0. We have 6 variables but only 4 equations, so pick 2 variables, set them to 0, and the equations give the other 4. The variables set to 0 are called out of the basis. The 4 computed ones are in the basis. “Basis” is just the name of the group of variables whose values we read in the table.

The easiest corner to start from: make nothing. Then x1 = x2 = 0 (out of the basis) and every leftover is full (in the basis).

  • corner (sommet)a point where two sides of the shape meet.A(300, 0)
  • basis (base)the variables we read in the table at the current corner. The others are 0.at O: x₃, x₄, x₅, x₆
  • in / out of the basis (variable dans la base, VDB / hors-base, VHB)in = has its own row in the table; out = set to 0.
  • simplex table (tableau du simplexe)one row per equation, one row for the profit Z, one column per variable, and a last column cste.

Step 1: what to increase (variable entrante)

↑ contents
In plain words

We are at O: nothing made, profit 0. To earn more, we start making something. The Z row tells us how much one extra unit of each variable adds to the profit: 7 for a luxury desk, 5 for a standard desk.

Rule: pick the biggest positive number in the Z row. Here that is luxury desks (x1). We say x1 enters the basis: it stops being 0 and gets its own row. If the Z row has no positive number, nothing can raise the profit: stop (section 7).

  • entering variable (variable entrante)the variable we start increasing; it goes from 0 to a positive value.x₁
  • Dantzig's rule (critère de Dantzig, plus grand gain marginal)choose the biggest positive number in the Z row.7 > 5, so x₁

Step 2: how far you can go (variable sortante, test du rapport)

↑ contents
In plain words

We now make more and more luxury desks, keeping x2 = 0. Every luxury desk uses up some leftovers. We must stop when the first leftover hits 0: one more desk would need a negative leftover, which is impossible.

For each row, compute cste ÷ (its number in the x1 column): that is how many desks fit before that row's leftover reaches 0. The smallest result wins. That row's variable becomes 0, so it leaves the basis. A row with 0 or a negative number in the column never limits us: skip it.

  • ratio (rapport, colonne C)cste ÷ number in the entering column, only where that number is positive.700 ÷ 2 = 350
  • leaving variable (variable sortante)the variable that reaches 0 first; it drops out of the basis.x₃
  • pivot (pivot)the number where the entering column and the leaving row cross.1

Step 3: rewrite the table (le pivotage)

↑ contents
In plain words

We have reached a new corner: x1 = 300 and x3 = 0. Now we redo the table so it describes this corner, the same way the first table described O. x1 takes over the row of x3, and the x1 column must become a 1 in that row and 0 everywhere else.

Two moves. (a) Divide the pivot row by the pivot, so the pivot becomes 1. (b) For every other row (the Z row too), subtract the right multiple of the new pivot row to turn its x1 number into 0. After that, the Z row again tells how much one extra unit of each variable earns from the new corner. Then go back to step 1.

  • pivot row (ligne pivot, Lp)the leaving variable's row, divided by the pivot.
  • row operation (combinaison de lignes)row − (its number in the entering column) × pivot row.Lx₆ − 2Lp
  • round (itération)steps 1, 2 and 3 once: one move to a neighbouring corner.

When to stop and how to read the answer (critère d'arrêt, lecture du résultat)

↑ contents
In plain words

Stop when the Z row has no positive number. Every possible change would then lower the profit (or leave it equal), so you are at the best corner.

Read the answer in the cste column: each variable in the basis equals its cste, every other variable is 0, and the profit is the Z-row cste without its minus sign.

  • optimal (optimal)no other allowed plan earns more.
  • stopping test (critère d'optimalité)every Z-row number ≤ 0 (when maximising).0, 0, 0, 0, −3, −2
  • level line (droite d'isoprofit)all plans with the same profit; a straight line.7x₁ + 5x₂ = 2900

When the pivot is not 1 (pivot différent de 1)

↑ contents
In plain words

Same three steps. The only difference: in step 3 the pivot is not 1, so you first divide the pivot row by the pivot to turn it into 1, and only then clear the rest of the column. Fractions appear. Keep them as fractions (55/7, not 7.86), or small rounding errors pile up.

With three products you can't draw the shape any more, but the table works exactly the same way.

  • dividing the pivot row (nouvelle ligne pivot)every number of the pivot row ÷ pivot.pivot 3: (1, 3, 2, 1, 0, 0 | 40) → (1/3, 1, 2/3, 1/3, 0, 0 | 40/3)

Several best plans (infinité de solutions)

↑ contents
In plain words

Sometimes a whole side of the shape is equally good: the “same profit” line lies flat along that side. The table shows it with a 0 in the Z row under a variable that is out of the basis (that is, currently 0). Increasing that variable changes nothing in the profit. So you can do one more round, reach the corner at the other end of that side, and the profit stays the same.

  • alternative optimum (solution optimale multiple)another plan with the same best profit.
  • 0 in the Z row (coefficient nul)at the end, a 0 under a variable out of the basis means a second best corner exists.Z = 100 − x₅ + 0·x₃

Numbers you can copy without computing (cases recopiées sans calcul)

↑ contents
In plain words

In step 3, many numbers don't change, and you can copy them straight across:

· A column with a 0 in the pivot row stays the same.
· A row with a 0 in the pivot column stays the same.
· The pivot row is just divided by the pivot, and the entering column becomes 1 in its row and 0 elsewhere.

  • unchanged column (colonne invariante)0 in the pivot row → copy the column.
  • unchanged row (ligne invariante)0 in the pivot column → copy the row.

Two equal numbers in the Z row (égalité des coefficients)

↑ contents
In plain words

If two variables share the biggest positive number in the Z row, the rule of step 1 can't choose. Do step 2 for both. Each one gains (its Z-row number) × (how far it can go). With equal numbers, choose the one that can go further, that is the bigger smallest-ratio.

  • gain of a round (accroissement de Z)Z-row number × how far the variable can go.2 × 50 = 100
  • tie (ex æquo)two equal biggest positive numbers in the Z row.

The rule is not always the fastest (Dantzig n'est pas le plus court chemin)

↑ contents
In plain words

Step 1 picks the best profit per unit, but ignores how many units you can actually add. So the simplex always ends at the best plan, but it may take a long detour. This example is built so that it visits all 8 corners.

  • greedy rule (règle gloutonne)a choice that looks best right now, without looking ahead.
  • neighbouring corners (sommets adjacents)two corners joined by a side; one round moves between them.

The example
