Adding scripts (intégrer un script)

↑ contents

Three places

<!-- 1. inline: code in an event attribute -->
<button onclick="doIncrement()">Incrémenter</button>

<!-- 2. <script> element, best at the end of <body> -->
<body>
  <h1 id="compt_H1">Compteur=0</h1>
  <script>
    document.getElementById("compt_H1").innerText = "Compteur=1";
  </script>
</body>

<!-- 3. external file, as many as needed -->
<script src="mon_script.js"></script>
<script src="https://cdn.example.com/lib.min.js"></script>

When does it run?

WhereRunsDOM ready?
<script> in <head>as soon as parsedNo: getElementById gives null
<script> at end of <body>after the elements above itYes
<script defer src>after full parse, in orderYes (external files only)
<script async src>as soon as downloaded, any orderNot guaranteed
<head>
  <script src="script.js" defer></script>
</head>
document.addEventListener("DOMContentLoaded", () => {
  // HTML parsed: safe to select elements
});
window.addEventListener("load", () => {
  // also images, CSS, iframes loaded
});

Output and comments

console.log("x =", 5);  // dev tools → Console tab
console.table([{ a: 1 }, { a: 2 }]);
console.error("oops");
alert("Bonjour");       // blocking pop-up
el.innerText = "Hi";    // into the page
// one line
/* several
   lines */

Semicolons ; are optional but recommended. No main(): code runs top to bottom.

Primitive types

let n = 42;
let s = "hi";
let b = true;
let u;
let z = null;
typeof n            // → "number" ← ints and floats alike
typeof s            // → "string"
typeof b            // → "boolean"
typeof u            // → "undefined"
typeof z            // → "object" ← old bug, null is primitive
typeof 10n          // → "bigint"
typeof Symbol()     // → "symbol"
typeof [1, 2]       // → "object"
typeof {}           // → "object"
typeof (() => 1)    // → "function"
Array.isArray([1])  // → true

Coercion (weak typing)

2 + "2"               // → "22" ← + concatenates strings
"6" * "2"             // → 12
"5" - 2               // → 3
"abc" * 2             // → NaN
Number("3.5")         // → 3.5

Falsy: false, 0, -0, 0n, "", null, undefined, NaN. Everything else is truthy, including [] and {}.

Arrays (tableaux)

↑ contents

Basics (mutating)

const a = [3, 1, 2];
a.length           // → 3
a[0]               // → 3
a.at(-1)           // → 2
a.push(4)          // → 4 ← returns new length
a.pop()            // → 4
a.unshift(0)       // → 4 ← add at start
a.shift()          // → 0 ← remove first
a.indexOf(2)       // → 2
a.includes(5)      // → false
a.join("-")        // → "3-1-2"
a.reverse()        // → [2, 1, 3]
const b = [1, 2, 3, 4];
b.splice(1, 2)     // → [2, 3] ← remove 2 items at index 1
b                  // → [1, 4]
b.splice(1, 0, 9)  // → [] ← insert 9 at index 1
b                  // → [1, 9, 4]

Callbacks (new array or value)

const n = [1, 2, 3, 4];
n.map(x => x * 2)                 // → [2, 4, 6, 8]
n.filter(x => x % 2 === 0)        // → [2, 4]
n.reduce((s, x) => s + x, 0)      // → 10
n.find(x => x > 2)                // → 3
n.findIndex(x => x > 2)           // → 2
n.some(x => x > 3)                // → true
n.every(x => x > 0)               // → true
n.slice(1, 3)                     // → [2, 3] ← copy, n unchanged
n.concat([5])                     // → [1, 2, 3, 4, 5]
[[1, 2], [3]].flat()              // → [1, 2, 3]
[10, 9, 1].sort()                 // → [1, 10, 9] ← string order!
[10, 9, 1].sort((x, y) => x - y)  // → [1, 9, 10]
Array.from("abc")                 // → ["a", "b", "c"]
Array(3).fill(0)                  // → [0, 0, 0]

Mutate the array: push, pop, shift, unshift, splice, sort, reverse, fill. The rest return something new.

Destructuring and spread

const [x, y, ...rest] = [10, 20, 30, 40];
x                       // → 10
rest                    // → [30, 40]
const [, second] = [1, 2, 3];
second                  // → 2
let p = 1, q = 2;
[p, q] = [q, p];        // swap
p                       // → 2
const tout = [...[1, 2], ...[3]];
tout                    // → [1, 2, 3]
Math.max(...[4, 9, 2])  // → 9

Objects and JSON (objets)

↑ contents

Object literal

const etudiant = { nom: "Ali", age: 20 };
etudiant.nom              // → "Ali"
etudiant["age"]           // → 20
etudiant.ville = "Oran";  // add
delete etudiant.age;      // remove
Object.keys(etudiant)     // → ["nom", "ville"]
Object.values(etudiant)   // → ["Ali", "Oran"]
Object.entries({ a: 1 })  // → [["a", 1]]
"nom" in etudiant         // → true
etudiant.tel              // → undefined
etudiant.tel?.fixe        // → undefined ← no error
const cle = "nom";
etudiant[cle]             // → "Ali"

Methods, shorthand, this

const nom = "Sara", age = 19;
const s = {
  nom, age,                       // = nom: nom, age: age
  saluer() { return `Salut ${this.nom}`; },
};
s.saluer()                        // → "Salut Sara"
const copie = { ...s, age: 21 };  // shallow copy + override
copie.age                         // → 21
s.age                             // → 19

Destructuring

const src = { nom: "Sara", ville: "Alger" };
const { nom, age = 18, ...autres } = src;
nom                                 // → "Sara"
age                                 // → 18 ← default used
autres                              // → { ville: "Alger" }
const { nom: n } = { nom: "Ali" };  // rename
n                                   // → "Ali"
function afficher({ nom, note }) { return `${nom}: ${note}`; }
afficher({ nom: "Ali", note: 15 })  // → "Ali: 15"

Array of objects and JSON

const etudiants = [
  { nom: "Ali", note: 15 },
  { nom: "Sara", note: 12 },
];
etudiants.map(e => e.nom)          // → ["Ali", "Sara"]
etudiants.filter(e => e.note >= 14).length  // → 1
const json = JSON.stringify(etudiants);
json                               // → '[{"nom":"Ali","note":15},{"nom":"Sara","note":12}]'
JSON.parse(json)[1].note           // → 12
JSON.stringify({ a: 1 }, null, 2)  // → '{\n  "a": 1\n}' ← pretty print

JSON: keys and strings in double quotes, no functions, no undefined, no trailing commas.

↑ contents

Arithmetic and assignment

7 / 2              // → 3.5 ← no integer division
Math.floor(7 / 2)  // → 3
7 % 3              // → 1
2 ** 10            // → 1024
0.1 + 0.2          // → 0.30000000000000004
1 / 0              // → Infinity
let i = 5;
i++                // → 5 ← returns old value
++i                // → 7
i += 3;            // also -= *= /= %= **=
i                  // → 10
Math.round(2.5)    // → 3
Math.abs(-4)       // → 4
Math.min(3, 1, 2)  // → 1

Math.random() gives [0, 1). Integer 1–6: Math.floor(Math.random() * 6) + 1.

Comparison (relational)

5 == "5"            // → true ← converts types
5 === "5"           // → false ← strict: use this
5 !== "5"           // → true
null == undefined   // → true
null === undefined  // → false
NaN === NaN         // → false
Number.isNaN(NaN)   // → true
"10" < "9"          // → true ← string order
10 < 9              // → false
[1] === [1]         // → false ← objects by reference

Logical

true && false                    // → false
true || false                    // → true
!true                            // → false
"a" && "b"                       // → "b" ← returns an operand
0 || "défaut"                    // → "défaut"
0 ?? "défaut"                    // → 0 ← only null/undefined
null ?? "défaut"                 // → "défaut"
let c = null;
c ??= 5;                         // also ||=  &&=
c                                // → 5
const age = 20;
age >= 18 ? "majeur" : "mineur"  // → "majeur"

Conditions and loops (conditions, boucles)

↑ contents

if / else if / else

function mention(note) {
  if (note >= 16) {
    return "Très bien";
  } else if (note >= 14) {
    return "Bien";
  } else if (note >= 10) {
    return "Passable";
  } else {
    return "Ajourné";
  }
}
mention(15)  // → "Bien"
mention(9)   // → "Ajourné"

switch

function action(feu) {
  let t;
  switch (feu) {  // compares with ===
    case "rouge":
      t = "stop";
      break;      // without break: falls through
    case "orange":
    case "jaune":
      t = "ralentir";
      break;
    default:
      t = "passer";
  }
  return t;
}
action("jaune")   // → "ralentir"
action("vert")    // → "passer"

Loops

const notes = [12, 8, 15];
let s = 0;
for (let i = 0; i < notes.length; i++) s += notes[i];
s                           // → 35
for (const v of notes) console.log(v);  // values: 12, 8, 15
for (const k in { a: 1, b: 2 }) console.log(k);  // keys: a, b
notes.forEach((v, i) => console.log(i, v));  // 0 12, 1 8, 2 15
let i = 0;
while (i < 3) i++;
i                           // → 3
do { i--; } while (i > 5);  // body runs at least once
i                           // → 2
for (const v of notes) {
  if (v < 10) continue;     // skip this one
  if (v > 14) break;        // stop the loop
}

forEach limits

for, for…offorEach
breakyesno (SyntaxError)
continueyesno; return skips to the next item
return from outer functionyesno, only leaves the callback
await one after anotheryesno
[1, 2, 3].forEach(x => { if (x === 2) return; console.log(x); });  // 1, 3
[1, 2, 3].forEach(x => { break; });  // ✕ SyntaxError
[1, 2, 3].some(x => x === 2)  // → true ← stops early

Asynchronous code (asynchrone)

↑ contents

Promise

function charger(ok) {
  return new Promise((resolve, reject) => {
    setTimeout(() => ok ? resolve("données") : reject(new Error("échec")), 500);
  });
}
charger(true)
  .then(d => console.log(d))  // données
  .catch(e => console.log(e.message))  // runs if rejected
  .finally(() => console.log("fini"));  // always

States: pending → fulfilled (resolve) or rejected (reject). Promise.all([p1, p2]) waits for all, fails if one fails.

async / await

async function main() {      // always returns a Promise
  try {
    const d = await charger(false);  // pauses main only
    console.log(d);
  } catch (e) {
    console.log(e.message);  // échec
  }
}
main();
const res = await fetch("/api/etudiants");
if (!res.ok) throw new Error(res.status);
const data = await res.json();

Event loop order

console.log("1");
setTimeout(() => console.log("2"), 0);  // task queue
Promise.resolve().then(() => console.log("3"));  // microtask queue
console.log("4");
// logs 1, 4, 3, 2
PartRole
Call stackruns synchronous code, one frame at a time (single thread)
Heapmemory for objects
Web APIstimers, fetch, DOM events run outside JS
Queuesmicrotasks (promises) first, then callbacks (tasks), once the stack is empty

Global vs local, strict mode

let g = "global";
function f() {
  let loc = "local";
  return g + " " + loc;      // inner sees outer
}
f()                          // → "global local"
function oubli() { x = 5; }  // no keyword: implicit global
oubli();
window.x                     // → 5

Put "use strict"; as the first line of a file or function. Use const by default, let when it changes, never var.

↑ contents

innerHTML vs innerText

const h1 = document.getElementById("compt_H1");
h1.innerHTML = "Compteur=<b>1</b>";  // parsed as HTML
h1.innerText                // → "Compteur=1"
h1.children.length          // → 1 ← the <b>
h1.innerText = "<b>2</b>";  // plain text, shown literally
h1.innerHTML                // → "&lt;b&gt;2&lt;/b&gt;"
h1.innerHTML += " !";       // append (re-parses everything)
h1.textContent              // → "<b>2</b> !"

innerText is what is visible (respects CSS). textContent is all the text. Never put user input in innerHTML.

Create and insert

Remove and replace

const box = document.getElementById("box");
const [t1, t2, t3] = box.children;
box.removeChild(t2);  // parent.removeChild(child)
t3.remove();          // the element removes itself

const box = document.getElementById("box");

[...box.children].map(h => h.innerText)  // → ["Titre1", "Titre3"]
t2.replaceWith(t1);        // newer form: old.replaceWith(new)

const btn = document.getElementById("btn");
btn.onclick = doTraitement;  // 2. property: one handler only
btn.addEventListener("click", doTraitement);  // 3. listener: many, removable
btn.removeEventListener("click", doTraitement);  // same function reference
btn.addEventListener("click", f, { once: true });  // runs once

Attribute and property use on + name (onclick). addEventListener uses the bare name ("click").

The event object

el.addEventListener("click", e => {
  e.type;                // "click"
  e.target;              // element actually clicked (may be a child)
  e.currentTarget;       // element the listener is on
  e.clientX; e.clientY;  // mouse position
  e.preventDefault();    // cancel default: link, submit, right-click menu
  e.stopPropagation();   // stop bubbling to parents
});
document.addEventListener("keydown", e => console.log(e.key));  // "Enter", "a"
input.addEventListener("input", e => console.log(e.target.value));
form.addEventListener("submit", e => { e.preventDefault(); /* validate */ });

Delegation (one listener for many children)

document.getElementById("box").addEventListener("click", e => {
  if (e.target.matches("h2")) e.target.classList.toggle("actif");
});

Works for children added later. Events bubble from the target up to document.

Notes on the original course
  • Slide 30 says “JavaScript (anciennement ECMAScript)”. It is the other way round: ECMAScript is the name of the standard JavaScript follows; the language was first called Mocha, then LiveScript.
  • Slide 41 heads the comparison operators “Rationnels”. They are relational operators (relationnels).
  • Slide 51 says var becomes global because of hoisting. var is function-scoped (it ignores blocks); hoisting only moves the declaration to the top of the function, with the value undefined. It is global only when declared outside any function.
  • Slide 139 lists the event as “dbclick”. The name is dblclick (the slide's own code uses the right one).
  • Slide 140 names the attributes “onmousover” and “onmousleave”. They are onmouseover and onmouseleave.
