2core
Two messages were encrypted with the same keystream. You know m₁ = 01000001 (the letter A) and see c₁ = 11100110 and c₂ = 11100010. Find m₂.
Aid
0 ⊕ 0 = 00 ⊕ 1 = 11 ⊕ 0 = 11 ⊕ 1 = 0
A 01000001B 01000010C 01000011D 01000100E 01000101F 01000110
Idea: c₁ ⊕ c₂ = (m₁ ⊕ s) ⊕ (m₂ ⊕ s) = m₁ ⊕ m₂. The keystream cancels.
Hint
First compute c₁ ⊕ c₂, then XOR the result with m₁.
Answer and steps
  • c₁ ⊕ c₂ = 00000100 (this equals m₁ ⊕ m₂).
  • m₂ = m₁ ⊕ 00000100 = 01000101, which is the letter E.

Modes of operation (Modes de chiffrement)

↑ contents

ECB, CBC and OFB on tiny 4-bit blocks, so you can see the mechanism without doing real encryption.

3warm-up
In ECB mode a message has five blocks: X Y X Z X (equal letters mean equal blocks). Which blocks, other than block 1, have the same ciphertext as block 1? Write their numbers.
AidECB: cᵢ = E_K(mᵢ). Each block is encrypted on its own, with nothing mixed in from its neighbours.
Hint
Same input block, same key, same function: same output.
Answer and steps
  • Blocks 3 and 5 equal block 1 (all are X), so their ciphertexts are equal too. Blocks 2 (Y) and 4 (Z) differ.
  • Answer: 35.

10warm-up
DES uses 8 S-boxes. Each takes 6 bits and outputs 4. Across all eight, how many bits go in and how many come out? Write the two numbers together (in, then out).
AidRound function: 32 bits → E → 48 bits → ⊕ key → eight S-boxes → 32 bits → P.
Hint
Multiply: 8 × 6 and 8 × 4.
Answer and steps
  • In: 8 × 6 = 48 bits. Out: 8 × 4 = 32 bits. The 48 → 32 drop is exactly what E (32 → 48) added earlier.
  • Answer: 4832.

IDEA (IDEA)

↑ contents

The two odd arithmetic operations, with the wrap-around rules written out.

13warm-up
IDEA addition ⊞ works modulo 2¹⁶ (16 bits). Compute FFF0 ⊞ 0030 in hex.
Aid
Add normally. If the result needs 17 bits (it reaches hex 10000 or more), drop the leading 1.
0 00001 00012 00103 00114 01005 01016 01107 01118 10009 1001A 1010B 1011C 1100D 1101E 1110F 1111
Hint
FFF0 + 0030 = 10020 in ordinary hex addition.
Answer and steps
  • FFF0 + 0030 = 10020. That is 17 bits, so drop the leading 1: 0020.
14core
IDEA multiplication ⊙ works modulo 2¹⁶ + 1 = 65537, and the 16-bit value 0000 stands for 2¹⁶ = 65536. Compute 0000 ⊙ 0005 in hex.
Aid
Shortcut: 2¹⁶ ≡ −1 (mod 65537), so 0000 ⊙ x = −x mod 65537 = 65537 − x.
0 00001 00012 00103 00114 01005 01016 01107 01118 10009 1001A 1010B 1011C 1100D 1101E 1110F 1111
Decimal to hex: 65532 = 15·4096 + 15·256 + 15·16 + 12.
Hint
Use the shortcut: the answer is 65537 − 5.
Answer and steps
  • 0000 means 65536, and 65536 × 5 mod 65537 = (−1) × 5 = −5 ≡ 65532.
  • 65532 in hex is FFFC (decimal 65532).
