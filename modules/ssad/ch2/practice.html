2core
This Caesar ciphertext has an unknown key. Decrypt it: XPPE LE ESP WTMCLCJ
Hint
Spot a 3-letter word that is probably THE. Which shift turns it into the ciphertext word?
Answer and steps
  • The 3-letter word ESP is probably THE. T = 19 became E = 4, so the shift is 4 − 19 = −15 ≡ 11 (mod 26): k = 11.
  • Decrypt by shifting back 11: MEET AT THE LIBRARY.

4core
Which of these affine keys are valid? (9, 5), (13, 4), (14, 1). For each invalid one, show two letters that collide.
Hint
Valid means gcd(a, 26) = 1. Only a matters, b is free.
Answer and steps
  • (9, 5): gcd(9, 26) = 1, valid.
  • (13, 4): gcd(13, 26) = 13, invalid. A (0) → 4 = E and C (2) → 13·2 + 4 = 30 ≡ 4 = E. Both give E.
  • (14, 1): gcd(14, 26) = 2, invalid. A (0) → 1 = B and N (13) → 14·13 + 1 = 183 ≡ 1 = B. Both give B.
5challenge
In a long affine ciphertext the most frequent letter is B and the second most frequent is K. Assume they stand for E and T. Recover the key (a, b).
Hint
E = 4 and B = 1, T = 19 and K = 10. Write two equations, subtract, and use the inverse of the coefficient of a.
Answer and steps
  • E → B: 4a + b ≡ 1. T → K: 19a + b ≡ 10 (mod 26).
  • Subtract: 15a ≡ 9. The inverse of 15 is 7 (15·7 = 105 ≡ 1), so a = 9·7 = 63 ≡ 11.
  • Then b ≡ 1 − 4·11 = −43 ≡ 9. Key: (11, 9). Check: gcd(11, 26) = 1, and 11·4 + 9 = 53 ≡ 1 = B ✓, 11·19 + 9 = 218 ≡ 10 = K ✓.

8challenge
A Kasiski test finds ciphertext chunks that repeat 12, 18 and 30 letters apart. Which key lengths are possible? A fourth chunk repeats 20 apart: what is the key length now?
Hint
The key length must divide every distance. Take the greatest common divisor.
Answer and steps
  • The key length divides 12, 18 and 30, so it divides gcd(12, 18, 30) = 6. Possible lengths: {2, 3, 6} (ignoring 1).
  • It must also divide 20. gcd(6, 20) = 2, so the key length is 2.

Hill (Chiffrement de Hill)

↑ contents

Matrices mod 26: validity, encryption, and decryption through the inverse.

10core
Which of these 2×2 Hill keys are valid mod 26? [[3, 2], [5, 7]], [[2, 4], [3, 6]], [[1, 2], [3, 4]].
Hint
Compute the determinant ad − bc and test gcd(det, 26) = 1.
Answer and steps
  • [[3, 2], [5, 7]]: det = 21 − 10 = 11, gcd(11, 26) = 1, valid.
  • [[2, 4], [3, 6]]: det = 12 − 12 = 0, invalid.
  • [[1, 2], [3, 4]]: det = 4 − 6 = −2 ≡ 24, gcd(24, 26) = 2, invalid.
11core
Encrypt GOLD with the Hill key K = [[2, 3], [1, 4]].
Hint
Check det(K) = 2·4 − 3·1 = 5 first. Then multiply K by each pair (G, O) and (L, D).
Answer and steps
  • det = 5 and gcd(5, 26) = 1, so K is valid.
  • GO = (6, 14): 2·6 + 3·14 = 54 → 2 = C; 1·6 + 4·14 = 62 → 10 = K
  • LD = (11, 3): 2·11 + 3·3 = 31 → 5 = F; 1·11 + 4·3 = 23 → 23 = X
  • Result: CKFX.
12challenge
Decrypt ELKC with the same key K = [[2, 3], [1, 4]].
Hint
Find 5⁻¹ mod 26 (extended Euclid), then K⁻¹ = det⁻¹ · [[d, −b], [−c, a]] mod 26.
Answer and steps
  • Inverse of the determinant: 26 = 5·5 + 1, so 1 = 26 − 5·5 and 5⁻¹ ≡ −5 ≡ 21 (check: 5·21 = 105 ≡ 1).
  • K⁻¹ = 21 · [[4, −3], [−1, 2]] = [[84, −63], [−21, 42]] ≡ [[6, 15], [5, 16]] mod 26.
  • EL = (4, 11): 6·4 + 15·11 = 189 → 7 = H; 5·4 + 16·11 = 196 → 14 = O
  • KC = (10, 2): 6·10 + 15·2 = 90 → 12 = M; 5·10 + 16·2 = 82 → 4 = E
  • Result: HOME.

Transposition (Transposition)

↑ contents

No letter changes, only the order. Decrypt a simple grid and encrypt with a keyword.

13core
Decrypt SOTAEUHTEAEEYTG, which was written in rows under 4 columns and read column by column.
Hint
15 letters in 4 columns: 15 mod 4 = 3, so the first 3 columns have 4 letters and the last has 3. Cut the ciphertext into those columns.
Answer and steps
  • Column lengths 4, 4, 4, 3 → columns SOTA, EUHT, EAEE, YTG.
  • Write them as columns, read by rows: SEEY, OUAT, THEG, ATE.
  • Result: SEEYOUATTHEGATE.
14challenge
Encrypt SECURITYISFUN with a complex columnar transposition, key CIPHER.
Hint
Write the message in rows of 6 under the key. Rank the key letters alphabetically (C, E, H, I, P, R), then read the columns in that order.
Answer and steps
  • Rows of 6: SECURI, TYISFU, N.
  • Alphabetical order of C-I-P-H-E-R: C=1, E=2, H=3, I=4, P=5, R=6, so read the columns of C, E, H, I, P, R in turn.
  • Columns read: STN RF US EY CI IU.
  • Result: STNRFUSEYCIIU.
