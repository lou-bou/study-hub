E

Definitions quiz Machines, tasks, criteria

0 / 12↑ contents

One correct answer each. Explanations appear after checking.

E1

Every task visits all machines, always in the same order. Which shop?

Flow shop (atelier à cheminement unique)

Flow shop: same order for every task. Open shop: no order imposed. Job shop: each task has its own route.

E2

A task can be stopped and resumed later (possibly elsewhere) at no cost. This mode is…

preemptive (avec préemption)

Preemption = the right to interrupt.

E3

pij = pi / bj describes…

uniform machines (machines uniformes)

Each machine has a constant speed factor bj; the speed does not depend on the task.

E4

The time a machine needs depends on the task in an arbitrary way. Which machines?

unrelated (machines générales)

Unrelated: arbitrary pij.

E5

What is the difference between a due date di and a deadline d̃i?

Missing a due date is allowed (it counts as lateness); missing a deadline is not allowed

Release date = available from; due date = target end; deadline = hard limit.

E6

Which of these can never be negative?

tardiness ti = max{li, 0}

Lateness is negative when a task ends early; tardiness clips it at 0.

E7

ui = 1 exactly when…

ci > di

Strictly later than the due date. Ending exactly on the due date is not tardy.

E8

The flow time fi equals…

ci − ri

Waiting time + processing time, counted from the release date.

E9

Which criterion counts the tasks that end after their due date?

NT = Σui

Add up the tardy indicators.

E10

Which pair are the two classical hypotheses?

a machine runs at most one task at a time, and a task runs on at most one machine at a time

These two are what make classical scheduling “classical”; real cases (batch machines, multiprocessor tasks) relax them.

E11

Each task has its own subset of machines and its own fixed order. Which shop?

Job shop

Job shop = routes are arbitrary but specified in advance.

E12

Ti < Tj means…

Ti must be finished before Tj starts

It is a precedence constraint, not a comparison of durations.
